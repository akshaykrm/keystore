## User

---

- A user is an individual person who can create an account on the platform.
- A user is able to create and manager workspaces or added to another workspaces
  by another user.
- Whenever a user creates a workspace they will be the owner of the workspace
  and this will be handled by membership relation.

---

### Responsibilities

- Authenticate
- Manage workspaces
- Join workspaces
- Manage profile

**Note**: A user does not own any catalogue, it is owned by workspaces

---

## Profile

User can manage their own profile

- Name
- Mobile Number
- Email
